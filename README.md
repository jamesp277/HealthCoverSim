# HealthCoverSim

A private health insurance quote simulator. You can create, view, edit and delete quotes, and each quote shows an estimated monthly and yearly premium.

Built with React (Vite), Node.js + Express and SQLite.

## How to install and run

You need Node.js 18 or newer.

```
npm run install:all
npm run dev
```

Then open http://localhost:5173. The API runs on http://localhost:3001.

## How the database is set up

The table is defined in `backend/init.sql`. `backend/db.js` creates `backend/healthcoversim.db` and runs the file whenever the server starts, using `CREATE TABLE IF NOT EXISTS`, so no manual step is needed. `npm run init-db` also creates it on its own. To start fresh, stop the server and delete the `.db` file.

Only the inputs are stored. The premium is calculated each time a quote is shown, so the pricing rules is in one place (`backend/calc.js`). The `applicant2_age` and `applicant2_cover_history` columns are NULL for Single cover.

## How the quote calculation works

Hospital and extras are calculated separately and then added.

```
hospital per adult = tier price x (1 + that adult's LHC loading)
hospital total     = sum of each adult's hospital price
extras total       = extras tier price x number of adults
family fee         = $30 for Family, otherwise $0
monthly premium    = hospital total + extras total + family fee
yearly before      = monthly premium x 12
yearly after       = yearly before x (1 - discount)
```

LHC loading applies to hospital cover only, for each applicant separately. If the history is "No" and the age is over 30, loading is (age - 30) x 2%. If the history is "Yes", the age is 30 or under, or hospital cover is None, loading is 0%. If the history is "Not sure", no loading is applied and a warning says the quote may be inaccurate.

## How Family cover is calculated

Family counts two adults, and each one pays their own hospital and extras price (with their own loading). A flat $30 per month family fee is added once. Children are not priced separately. Couple cover is the same but without the $30 fee.

## Validation

The form checks required fields, ages from 18 to 100, a discount from 0 to 10, and that Applicant 2 is filled in for Couple and Family. The backend runs the same checks again and returns a 400 with an error message for each bad field, so invalid requests sent straight to the API do not crash the server.

## AI use statement

Tool used: ChatGPT.

What it helped with: 
I used ChatGPT to generate the starter code for SQLite table, the React pages & form, as well as to understand the logic of the pricing rules.

What I checked or implemented myself: 
I created the express routes & CSS and further reviewed & refined the code generated by ChatGPT.

One decision I made myself:
I decided to store the input fields in database and calculate the premium when a quote is displayed. Thus the pricing rules is in one file and an edited quote will not show an outdated price.

## Limitation

The loading rule is simplified. It has no cap and does not drop away after years of continuous cover. In addition, prices do not change with age, state or income, so the quote is not an estimate of any real policy.
