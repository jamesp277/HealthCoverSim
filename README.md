# HealthCoverSim

A private health insurance quote simulator. You can create, view, edit, delete quotes, and each quote shows an estimated monthly and yearly premium.

Built with React (Vite), Node.js + Express and SQLite. 

# How to install and run

You need Node.js 18 or newer.

```
npm run install:all
npm run dev
```

Then open http://localhost:5173. The API runs on http://localhost:3001.
